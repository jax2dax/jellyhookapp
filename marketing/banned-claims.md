# Banned claims

Never write these, in any channel, even softened.

| Banned | Why |
|---|---|
| "session replay", "recordings", "watch visitors" | It is a chart, not a video. Sets the wrong expectation. |
| "identify visitors", "find out who is on your site", company/name of anonymous visitors | Not supported. Names exist only after a form submit. |
| "lead intelligence" as a headline or category | Implies identification; puts us next to bigger tools. |
| "GDPR compliant", "CCPA compliant", "no consent needed", "cookieless", "privacy-first" as a guarantee | The tracker now honours Global Privacy Control / Do Not Track and has an optional consent mode (data-require-consent), but compliance is the site owner's job and nothing here is legal advice. Say what the tracker does, never "compliant". |
| "close more deals", "increase conversions by X%", "more leads", any result promise | Nothing proves outcomes. |
| Any number of users, customers, leads, revenue, uplift, or testimonial not in `marketing/metrics.md` | Invented figures. |
| "integrates with HubSpot / Salesforce / any CRM" | No integration exists. |
| "detects broken links, bad UI, unclear content" | No such feature. |
| "AI" anything, "intent score", "lead scoring", "engagement score", "confidence" | Excluded on purpose (roadmap) or not real. |
| "page health" as a feature | Excluded on purpose. |
| Acquisition page, Intent page | Excluded on purpose. |
| "Hook is live for everyone" | Production setup UNVERIFIED. |
| Naming competitors in ads or public posts | Founder rule. |
| Fake urgency ("only 10 spots") unless it is literally true and the founder confirms | Honesty. |
