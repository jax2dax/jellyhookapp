# Weekly plan

1. Run `date`. State today's date and weekday. Plan from today to the end of next Sunday if it is already late in the week.
2. Read the memory files listed at the top of `.claude/agents/marketing-manager.md`. Follow that agent's rules.
3. Check the product state (`git log --oneline -15`). If something shipped that changes what can be claimed, update
   `marketing/claims-ledger.md` first.
4. Write `marketing/calendar/YYYY-Www.md` with, per day: (a) actions in time order, each with when, where,
   exact text, metric and threshold, why now; (b) what the founder must supply (names, numbers, screenshots).
5. Typical weekly shape (adjust to the data): 2 days building the named target list and first lines, 3 days sending
   personalised messages (small numbers, each different), 1 standalone content piece, 1 review. No broadcast posting.
6. End with: the 3 product changes that would help marketing most, and what the founder does first today.
